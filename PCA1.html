El problema:

Sea un punto \(x\in\mathbb{R}^{p}\), representamos a un conjunto de puntos \(\{x_i\}_{i=1}^{n}\) con una matrix \(\mathbf{X}\in \mathbb{R}^{n\times p}\).

Una representación de los datos con dimensión reducida busca una matrix \(\mathbf{B}^*\) con \(\mathrm{rank}(\mathbf{X})\leq k, \quad k < \min(n,p)\), tal que

\[\begin{equation} \mathbf{B}^* = \mathrm{argmin}_{\mathbf{B}}||\mathbf{X} - \mathbf{B}|| \end{equation}\]

Solución

Teorema de Eckart-Young-Mirsky

Eckart y Young (1936) probaron que la solución para la norma de Frobenius, la solución está dada por lo que más tarde se le llamó como decomposición SDV. Más tarde Mirsky (1960) generalizó la prueva para cualquier norma invariante ante multiplicaciones por matrices unitarias.

Recordando

La norma de Frobenius es, \[\begin{equation} ||\mathbf{X}-\mathbf{B}||_F^2 = \sum_{i=1}^{n}\sum_{j=1}^{p}(x_{ij}-b_{ij})^2. \end{equation}\]

Decomposición SVD:

Toda matrix puede escribirse en su decomposición SVD como \(\mathbf{X} = \mathbf{U}\mathbf{\Lambda} \mathbf{V}^T\); \(\mathbf{U}\in \mathbb{R}^{n\times n}\), \(\mathbf{V}\in\mathbb{R}^{p\times p}\) ortogonales, e.g. \(\mathbf{U}^T\mathbf{U} = \mathbf{I}\), y \(\mathbf{\Lambda}\in\mathbb{R}^{n\times p}\) una matris rectangular diagonal con elementos positivos llamados .

¿Cómo se usa la decomposición SVD para approximar la matris?

Eckart y Young, años despues generalizado por Mirsky, mostraron que la aproximación optima esta dada por: \[\begin{equation} \begin{split} &\hat{\mathbf{X}} = {\mathbf{U}} \hat{\mathbf{\Psi}}{\mathbf{V}}^T = \hat{\mathbf{U}}_r \hat{\mathbf{\Psi}}_r\hat{\mathbf{V}}_r^T, \\ &\mathrm{diag}(\hat{\Psi}) = (\mathbf{\psi_1},\cdots,\mathbf{\psi_r},0,\cdots,0) \end{split} \end{equation}\] en donde \({\mathbf{U}}_r \in \mathbb{R}^{m\times r}\) es la versión truncada de \(\mathbf{U}\), dejando unicamente las primeras \(r\) columns.

Código 
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# ============================================================
# 1. Generate data from the original plane equation
# ============================================================

rng = np.random.default_rng(42)

n_points = 100

x = rng.uniform(-10, 10, n_points)
y = rng.uniform(-10, 10, n_points)

z = 0.75 * x - 0.55 * y + 0.4 + rng.normal(0.0, 2.2, n_points)

# Data matrix (NO centering)
X = np.column_stack((x, y, z))

# ============================================================
# 2. Compute SVD
# ============================================================

U, S, Vt = np.linalg.svd(X, full_matrices=False)

# Singular values
print("Singular values:")
print(S)

# ============================================================
# 3. Rank-k approximations
# ============================================================

def reconstruct(k):
    return U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]

# Energy captured by each rank-k approximation
total_energy = np.sum(S**2)

energy = np.cumsum(S**2) / total_energy

print("\nEnergy captured:")
for k in range(1, 4):
    print(f"Rank {k}: {energy[k-1]*100:.2f}%")
